# Movie-Recommendation-Prediction

## Tools & Technologies Used
Python

Pandas – for data manipulation

NumPy – for array handling

Scikit-learn – for building similarity models

Google Colab – for notebook execution

Cosine Similarity – for recommendation logic

## Models & Techniques
Content-Based Filtering using:

TF-IDF Vectorization on genres and metadata

Cosine similarity between movie vectors

Simple Nearest Neighbor Search using similarity matrices

## Results
Successfully recommends top 5–10 similar movies based on a selected title.

Example: Entering “The Dark Knight” returns highly relevant action/crime films like “Batman Begins” and “Inception.”

Achieves intuitive results without needing user ratings, purely from content features.
